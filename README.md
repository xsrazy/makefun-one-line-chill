# makefun-one-line-chill

[![make.fun · u-azazex-one-line-one-chill-6d4d5488](https://make.fun/badge/u-azazex-one-line-one-chill-6d4d5488.svg)](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488?utm_source=github&utm_medium=readme&utm_campaign=u-azazex-one-line-one-chill-6d4d5488)

One line of horror, one sentence, one breath: a child's nightly goodnight to an empty corner, answered back in the parent's own voice. The program writes the sentence to `entry.txt` (UTF-8, 126 characters, no trailing newline).

> Every night my son says goodnight to the empty corner of his room, and last night the corner said goodnight back, in my voice.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-line-chill-out python3 main.py
```
